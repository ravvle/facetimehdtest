# Driver patch series

The changes in [`../src/facetimehd/`](../src/facetimehd/) as a numbered patch
series against **`patjak/facetimehd` commit `54fb8f2`** (upstream `master` at
the time of generation), for review or for proposing individual changes
upstream.

This is a generated view. The review record for the fork - what each change
does and why - is
[`../src/facetimehd/DOWNSTREAM.md`](../src/facetimehd/DOWNSTREAM.md); nothing
in `scripts/`, `tests/` or CI reads these files, and they are regenerated by
hand when the fork moves.

Apply with `git am` on an upstream checkout:

```bash
git clone https://github.com/patjak/facetimehd
cd facetimehd && git checkout 54fb8f2
git am /path/to/driver-patches/*.patch
```

The result is byte-for-byte `src/facetimehd/`, minus the files that are not
driver source: `DOWNSTREAM.md`, `FIRMWARE-REVERSE-ENGINEERING.md`,
`.gitignore` and upstream's `README.md`.

The base is upstream `master`, not the `364b1c6` fork point named in
`DOWNSTREAM.md`. Four of the fork's changes have been merged upstream since
then - the `y1` crop-command assignment, capping the buffer count with
`FTHD_BUFFERS`, the missing `break` after the auto-white-balance case, and
omitting `v4l2_fmtdesc.description` on kernels that ignore it - so they are
part of the base rather than of this series.
